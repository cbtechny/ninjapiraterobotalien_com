# Sackjack Island Redesign Planning Hub

This directory serves as the centralized planning and architectural documentation for the upcoming website redesign of Ninja Pirate Robot Alien Games. The project focuses on pivoting the site to a Sackjack Island-centric experience with a streamlined "Digital Press Kit" approach.

## Target Structure
The redesigned site will transition from its current multi-page structure to a simplified 3-page model:
- **HOME**: The primary showcase for Sackjack Island, designed to capture attention and provide immediate game context.
- **DEVLOG**: A modernized development blog featuring updates, news, and technical insights.
- **ABOUT**: A consolidated information hub combining studio background and contact information.
