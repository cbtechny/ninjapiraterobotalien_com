# Redesign Planning Hub: Sackjack Island focus

This directory contains the strategic and technical planning documents for the upcoming redesign of the Ninja Pirate Robot Alien Games website.

## Purpose

The goal of this planning hub is to provide a structured roadmap for consolidating the current multi-page site into a lean, high-impact, three-page "digital press kit" focused on our flagship project, **Sackjack Island**.

## Target Site Structure

The redesigned site will be simplified to three primary destinations:

1.  **HOME**: A high-energy landing page focused on Sackjack Island.
2.  **DEVLOG**: A chronological record of development progress and updates.
3.  **ABOUT**: Information about the studio and contact details.
