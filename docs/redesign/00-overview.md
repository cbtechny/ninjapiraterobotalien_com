# 00: Project Overview

This document outlines the high-level goals and visual direction for the Sackjack Island website redesign.

## Redesign Goal
The primary objective is to redesign the current Ninja Pirate Robot Alien Games studio website to prioritize the studio's key project, **Sackjack Island**. The goal is a streamlined, high-performance, 3-page site that focuses on visual impact and immediate game context.

## Digital Press Kit Framing
The redesign is framed as a **Digital Press Kit**. This means the site's primary function is to:
- Showcase high-quality screenshots and visual assets.
- Provide clear, concise "fact sheet" style information about the game.
- Facilitate quick access to essential game information for media, partners, and fans.
- Prioritize visual storytelling over heavy text blocks.

## Visual Direction
The desired visual direction is a "clean but vibrant" aesthetic that highlights game art while maintaining a modern feel.

### Key Visual Goals:
- High-impact imagery (Sackjack-focused).
- Modern, crisp typography.
- Performance-focused layouts.

### Non-Goals (Avoid These):
- **Sluggish Interaction**: Heavy animations or complex scripts that delay user interaction.
- **Slow Performance**: Large unoptimized assets or excessive HTTP requests.
- **Heavy Gradients**: Overly complex or "muddy" gradients that detract from the core game art.
- **Overengineering**: Moving away from a static-site friendly architecture to unnecessary frameworks.

## Target 3-Page Structure
The site will be consolidated into three primary pages:
1. **HOME**: A Sackjack-focused showcase landing page.
2. **DEVLOG**: A modernized version of the development blog.
3. **ABOUT**: A combined page for studio details, "About Sackjack," and contact info.

## Implementation Constraints
- **Static-Site Friendly**: The site must remain hostable on static platforms (e.g., GitHub Pages).
- **Placeholder Imagery**: High-quality placeholders are allowed during development if final assets are not yet available.
- **Primary Focus**: All design elements should lead back to or support the Sackjack Island brand.
- **Maintain Current Tech Stack**: Continue using the modular partials-based injection system (header, footer) for consistency and manageability.
