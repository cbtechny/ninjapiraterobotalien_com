# 04: Design System

This document defines the visual language, typography, and color palette for the Sackjack Island redesign, avoiding heavy gradients for a cleaner, faster experience.

## Visual Language
The redesign adopts a "clean but vibrant" aesthetic that highlights game art while maintaining high performance.

### Key Visual Principles:
- **Clarity**: High contrast and readable typography.
- **Vibrancy**: Use color for emphasis, not as the primary background element.
- **Focus**: Design elements should not detract from the Sackjack artwork.

- **Text**: Dark Gray/Black for readability on light backgrounds.

## Typography
- **Headlines**: Bold, modern sans-serif.
- **Body Text**: Readable sans-serif for long-form content.
- **Typography Goals**: Crisp, fast-loading, and responsive sizing.

- [ ] **Buttons**: Simple, solid colors or minimal subtle gradients.

- [ ] **Navigation**: Minimal, sticky header with text-based links.
- [ ] **Modals/Lightboxes**: Lightweight implementation for screenshots.

## Icons
- [ ] **Social Icons**: Simple, flat icons.

## Performance-Focused Implementation
- **Minimal CSS**: Focus on utility classes or a lightweight custom CSS file.
- **Font Optimization**: Use `preconnect` for external fonts (Google Fonts) and avoid excessive weights.
- **Asset Loading**: Implement lazy loading for images and gallery assets.
