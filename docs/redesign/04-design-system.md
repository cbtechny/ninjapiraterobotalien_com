# 04 - Design System: Vibrant Comic Aesthetics

This document outlines the visual language and reusable components for the Ninja Pirate Robot Alien redesign.

## Purpose

The design system ensures a consistent, high-energy aesthetic across all three pages of the new site. It's built around the **Sackjack Island** vibrant world and the studio's "Ninja Pirate Robot Alien" (NPRA) attitude.

## Visual Language

-   **Color Palette**:
    -   Primary: Vibrant, neon-inspired colors (e.g., #FFD700 (Gold), #FF4500 (OrangeRed), #1E90FF (DodgerBlue)).
    -   Secondary: Bold, deep blacks for borders and shadows (#000000).
    -   Backgrounds: High-energy gradients that reflect the game's world.
-   **Typography**:
    -   Headings: Bold, punchy, "comic-book" style font (e.g., "Bangers" or "Permanent Marker" via Google Fonts).
    -   Body: Clean, sans-serif font for readability (e.g., "Inter" or "Montserrat").
-   **Visual Elements**:
    -   Thick black borders (2px to 4px).
    -   Bold, hard shadows for buttons and containers.
    -   Speech bubbles or "POW!" style graphic elements for UI.

## Reusable Components

-   **Buttons**: High-impact CTAs with bold borders and hover animations.
-   **Cards**: Consistent styling for devlog posts and team bios.
-   **Header**: Sticky navigation with the NPRA logo and primary links (HOME, DEVLOG, ABOUT).
-   **Footer**: Social media links, studio info, and copyright.

## Implementation Details

-   Use CSS variables for colors, spacing, and typography to ensure global consistency.
-   Utility classes for borders, shadows, and gradients.
-   Responsive design at the 768px breakpoint.
